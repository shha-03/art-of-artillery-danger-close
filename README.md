# Art of Artillery: Danger Close

불변식을 작성해 공격 영역을 정하는 2D 포격 퍼즐입니다. 포대장은 고정된 프로그램을 관찰하고, 아군을 피하면서 여러 적을 한 번의 일제사로 제거할 수 있는 조건을 찾습니다.

## 실행

프로젝트 디렉터리에서 다음 명령을 실행한 뒤, 터미널에 출력된 주소를 브라우저로 여세요.

```sh
node server.mjs
```

검증 엔진의 자동 테스트는 다음과 같이 실행합니다.

```sh
node --test engine.test.mjs
```

게임 화면과 레벨 데이터는 `dist/`에 있습니다. 별도의 빌드 없이 정적 웹 서버로 제공할 수 있습니다.

## 게임 방법

1. 전장의 적, 아군, 중립 칸과 고정된 초기값·반복 조건·반복문 본문을 확인합니다.
2. 변수 `x`, `y`에 대한 불변식 `I`를 작성합니다. 비교 연산과 `&&`, `||`, 괄호를 사용해 영역을 표현할 수 있습니다.
3. 전장 배치를 보고 원하는 종료 상태 조건인 `ensures`, 즉 목표 `Q`를 작성합니다.
4. 초기 성립, 반복 보존, 목표 보장 결과와 반례를 확인하며 조건을 수정합니다.
5. 단발 또는 일제사 명령을 내려 적을 제거합니다. 라운드마다 명령은 6회입니다.

공격 후보는 다음 조건을 모두 만족하는 전장 좌표입니다.

```text
S = I && !guard
```

초기값에서 `I`가 참이고, `I && guard`인 모든 검증 상태에 본문을 한 번 실행해도 `I`가 유지되어야 발사할 수 있습니다. 이 두 검사 중 하나라도 실패하면 불발입니다. `I && !guard`가 `Q`를 보장하는지는 별도로 표시하며, 목표 조건을 바꾼다고 공격 후보 자체가 바뀌지는 않습니다.

초기 성립 실패는 초기 상태를, 반복 보존 실패는 반복 전후의 상태를, 목표 보장 실패는 목표를 만족하지 않는 종료 후보를 보여줍니다. 이 반례를 이용해 불변식이나 목표를 수정하세요.

## 포격과 점수

- 단발은 공격 후보 중 한 칸을 포격합니다. 일제사는 공격 후보 전체를 포격합니다.
- 두 방식 모두 명령 1회만 사용합니다. 일제사의 발사 수가 많아져도 명령 비용은 늘어나지 않습니다.
- 표적 우선순위는 중립 칸 → 아군 → 적입니다. 같은 종류에서는 고정된 좌표순을 사용합니다.
- 포격을 완료한 칸은 이후 후보에서 제외됩니다. 파괴된 적·아군의 칸도 중립 칸으로 다시 공격하지 않습니다.
- 빈칸은 중립 칸입니다. 중립 칸 포격 자체에는 처치 점수가 없습니다.

```text
점수 = 적 처치 수 - 아군 처치 수 + 남은 명령 횟수
```

단발로 적 한 기를 처치하면 처치 점수와 명령 비용이 상쇄됩니다. 일제사로 적 여러 기를 함께 제거하면 점수가 올라갑니다. 중립 칸은 일제사에서 추가 명령 비용을 만들지 않으므로, 아군을 제외하는 조건을 찾는 것이 중요합니다.

## 네 개의 작전

| 작전 | 반복문의 특징 | 찾을 관계 |
| --- | --- | --- |
| 01. 대각선 교두보 | `x`, `y`가 함께 1씩 증가 | 같은 값의 관계와 공격 영역의 상한 |
| 02. 협곡 호송대 | `x`만 증가 | 변하지 않는 `y`와 범위의 결합 |
| 03. 두 배의 고도 | `x`는 1, `y`는 2씩 증가 | `y = 2 * x`라는 선형 관계 |
| 04. 능선 너머 | `x = 2`에서 `y`의 증감 방향 변경 | 두 구간의 관계를 논리합으로 연결 |

각 작전에는 단계별 힌트 세 개가 있습니다. 마지막 힌트는 예시 불변식입니다. 레벨 데이터의 `solution`과 `goalSolution`에는 검증 가능한 예시를 제공합니다.

## 검증 범위와 설계

검증 엔진은 `x`, `y`가 각각 -32부터 32까지인 모든 정수 상태를 검사합니다. 화면의 9×9 전장보다 넓은 유한 상태 공간에 대한 정확한 열거 검사이며, 무한한 정수 전체에 대한 정리 증명은 아닙니다. 반복 보존 검사에서 전이 결과를 경계로 잘라내거나 경계 밖으로 나가는 전이를 무시하지 않습니다. 결과가 검증 범위를 벗어나면 보존 실패로 처리합니다.

불변식은 실제로 도달하지 않는 상태도 포함할 수 있습니다. 이 게임은 검증된 불변식이 허용하는 종료 후보 영역을 포격 영역으로 사용합니다. 따라서 고정된 결정적 프로그램의 실제 종료 좌표가 하나여도, 여러 후보 좌표를 한 번에 공격할 수 있습니다. 종료 여부 자체를 증명하는 게임은 아닙니다.

플레이어의 수정을 이끄는 핵심은 세 종류의 반례, 전장 위의 공격 영역, 단발과 일제사의 선택입니다. 프로그램은 고정하고 불변식과 목표만 편집하게 해, 조건을 좁히는 행동이 공격 결과에 직접 연결되도록 설계했습니다.
